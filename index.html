⚠ 为什么要「已审计」——旧版本的错误（点击展开）
早期版本（2026-10-29 之前）存在信号簇重复触发缺陷：恐慌期 B≥35% 会断续出现， 中间只隔 1~2 天，旧代码把每段都当新信号独立买入，导致同一波下跌被重复计数、 持仓区间互相重叠（最多时 30 处）。
方案 笔数 重叠 单笔净 年化(净)
旧版（无去重） 245 30 +1.877% +32.1%
现行（簇合并3日+冷却） 150 0 +1.993% +19.7%
注意：去重后单笔收益反而升高（+1.877% → +1.993%），说明旧版多出来的笔 质量更差；旧版的高年化主要来源是资金周转次数虚增，不是收益质量更高。
同时修复了第二个错误：市场日均涨幅曾先在全表计算、再做可交易过滤， 导致极端涨幅（如某股复牌首日 +315%）通过切片副本"复活"，污染了 155 天的市场均值 （最大偏差 9.48pp，24 天涨跌方向反转），进而影响「等阳线」判断。现已改为先过滤后计算。
已交叉验证的无误项：信号方向性（B≥35% 未来3日 +0.391%）、 shift(1) 防未来函数、B/T 广度聚合、阈值分位、等阳线进场逻辑—— 网页数据反向审计 10 项全 PASS。

算法公式（点击折叠）
# 1. 个股贴底/贴顶幅度（分母排除当日，避免未来函数） low_60(t) = min( low[t-60 : t-1] ) g(t) = close(t) / low_60(t) - 1 // 贴底幅度 high_60(t) = max( high[t-60 : t-1] ) G(t) = close(t) / high_60(t) - 1 // 贴顶幅度 # 2. 全市场广度（占比，不是幅度） B(t) = mean( g(t) <= +2% ) × 100 // 贴底比例 T(t) = mean( G(t) >= -2% ) × 100 // 贴顶比例 # 3. 触发与进场 若 B(t) >= 35% → 等首根阳线（≤10 日）买入，持 3 日 若 T(t) >= 11.8%（90 分位）→ 当日尾盘 14:55 买入，持 3 日 # 4. 卖出：唯一规则 = 到期无条件卖出 sell(t) = t + 3 // 不止损、不逃顶、不移动止盈
为什么等阳线
贴底当天买胜率仅 22%、单笔 −2.71%；等阳线后 +1.93%、胜率 66%。
为什么不等顶部
贴顶次日开盘买只剩 +0.56%（衰减 59%），必须当日尾盘执行。
为什么不止损
−3% 止损胜率 41%、效率 0.09%/日，全场最差——会砍掉右尾。
为什么 3 日
效率 0.87%/日；持 5 日 0.62%、持 20 日 0.24%。
为什么 OFF 空仓
OFF 期市场 3 日期望 +0.01%（IR 0.03），66 种因子组合扣成本后 0 个为正。
